Install or update your copy

On Windows, place slide-web-viewer-personal.xml in your existing trusted add-ins folder. For updates, replace the previous personal XML. Close all PowerPoint windows, reopen, refresh Shared Folder and select Slide Web Viewer (personal). On a new slide, paste a URL and save the deck.

Keep the XML with your presentation. Others can use the same personal file where local installation is permitted. Slides inserted from the university-managed viewer keep their original add-in identity.
