QUB Slide Studio

Add a live webpage or teaching activity to an open PowerPoint presentation.

Download both Windows pilot files

Set up the lectern once

  1. Extract the two XML files into a WorkshopAddins shared folder that this Windows PC trusts and can reach while your laptop is off. Replace any older copies. First-time folder setup
  2. In desktop PowerPoint, select Home → Add-ins → Advanced → Shared Folder → Refresh. Add QUB Slide Studio. If an old version still appears, save your work, restart PowerPoint and refresh again.
  3. In the panel, open Viewer setup, choose Windows shared test folder and paste the same network folder address PowerPoint trusts. If Windows copied a label and parentheses, keep just the address.

Try a slide

Select a slide thumbnail. Open Home → QUB Slide Studio, choose QUBlet sticky notes → Queen’s acronyms and click Insert new slide. Run Slide Show and choose Check my recall.
